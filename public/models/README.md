# Models Directory

Place your custom Mazda MX-5 model here as `miata.glb`.

Ensure the model adheres to the node contract:
- `headlight_L`: Group or Object3D pivoted at the rear hinge edge of the driver/left lamp, rotating on local X axis.
- `headlight_R`: Group or Object3D pivoted at the rear hinge edge of the passenger/right lamp, rotating on local X axis.
